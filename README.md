# 📖 Blog App

Welcome to the **Blog App** repository!  
This is a **full-stack, Dockerized blog platform** where users can create, edit, and share blog posts. The app is optimized for modern development workflows with containerization, seamless UI, and secure authentication.

---

## 🚀 Features

- 📝 Create, read, update, and delete blog posts.
- 🔐 JWT-based user authentication.
- 📦 Fully containerized with Docker and Docker Compose.
- 🎨 Responsive UI with Tailwind CSS.
- 🧭 Client-side routing with React Router.
- ⚡ Real-time backend API with Express.js.

---

## 🛠️ Tech Stack

### Frontend:
- ⚛️ **React.js** – Component-based UI
- 🎨 **Tailwind CSS** – Utility-first CSS framework
- 📡 **Axios** – HTTP client
- 🧭 **React Router** – SPA navigation

### Backend:
- 🟢 **Node.js** with **Express.js** – REST API
- 🛡️ **JWT** – Authentication
- 🔒 **Bcrypt** – Secure password hashing
- 🛠️ **Mongoose** – MongoDB ODM

### Database:
- 🗄️ **MongoDB** – NoSQL database

### DevOps / Deployment:
- 🐳 **Docker** – Containerization
- 🛠️ **Docker Compose** – Multi-container orchestration
- 🌐 **Nginx** – Production-ready reverse proxy for frontend
